# Sistema de Gestión de Biblioteca

## Descripción

Sistema desarrollado para la administración y gestión de una biblioteca, permitiendo el control de libros, préstamos, usuarios y procesos administrativos relacionados con el manejo del acervo bibliográfico.

El proyecto fue desarrollado como parte de las actividades académicas de la materia de Ambientes Colaborativos y Control de Versiones Git.

---

## Objetivos

- Automatizar el control de libros.
- Gestionar préstamos y devoluciones.
- Administrar usuarios del sistema.
- Mantener un registro organizado de la información bibliográfica.
- Facilitar la consulta y administración de recursos de la biblioteca.

---

## Características Principales

Registro de libros
Consulta de catálogo
Administración de usuarios
Control de préstamos
Control de devoluciones

## Instalación

### 1. Clonar el repositorio

```bash
git clone https://github.com/angelvaldez20622/Biblioteca.git
```

### 2. Ingresar al proyecto

```bash
cd Biblioteca
```

### 3. Instalar dependencias

```bash
npm install
```

### 4. Configurar la base de datos

Crear una base de datos en MySQL e importar el script correspondiente.

Configurar las credenciales de conexión en el archivo:

```env
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=
DB_NAME=biblioteca
```

### 5. Ejecutar el sistema

```bash
npm start
```

o

```bash
node app.js
```
